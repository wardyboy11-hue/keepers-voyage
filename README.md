# Keeper's Voyage

Private family PWA for Ell (U11 Wigan Athletic academy goalkeeper).

## Files
All the app files are in this folder. Upload the **contents** of this folder to a GitHub repository.

## Quick GitHub Pages setup
1. Create a new public repository on GitHub called `keepers-voyage`.
2. Upload every file and folder from this directory (index.html, app.js, style.css, sw.js, manifest.json, assets/, icons/).
3. Go to Settings → Pages.
4. Source: Deploy from a branch → main → / (root) → Save.
5. Your live link will appear at the top of the Pages settings (usually https://YOUR-USERNAME.github.io/keepers-voyage/).

## Install on iPhone
1. Open the live link in Safari.
2. Tap Share → Add to Home Screen.
3. The custom logo will appear.

Data stays on the phone only. Works offline after the first load.
